# kintore-checker

カレンダーでトレーニングの達成日をチェックすると、隠れた画像が1マスずつ開いていく習慣トラッカー。

- `index.html` — 本体。1ファイルで完結し、ビルドは不要
- `demo.html` — 仮画像を埋め込んだ動作デモ

## データの扱い

登録した画像は端末のブラウザ内（IndexedDB）に、達成記録と設定は localStorage に保存される。
通信は発生せず、このリポジトリにも画像は含まれない。

ブラウザのサイトデータを消すと、登録した画像と記録も消える。

## 使い方

公開URLを iPhone の Safari で開き、共有メニューから「ホーム画面に追加」する。
以降はホーム画面のアイコンから全画面で起動する。
