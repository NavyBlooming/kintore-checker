# kintore-checker

トレーニングのセットを完了させると、隠れた画像が少しずつ開いていく習慣トラッカー。
1セット完了で6マス、1回のトレーニング（3種目）で18マス開く。

## 構成

| ファイル | 役割 |
| --- | --- |
| `app.js` | 画面のマークアップと全機能。本体・デモの両方がこれを読む |
| `app.css` | スタイル |
| `index.html` | 本体。`KC_CONFIG = { demo: false }` を渡すだけ |
| `demo.html` | デモ。`{ demo: true }` とサンプル素材を渡すだけ |

本体とデモの仕様がずれないよう、画面と処理は `app.js` に集約している。
デモ側で変わるのは次の3点だけ。

1. 保存先を分ける（同じオリジンなので、本体の記録を壊さないため）
2. デバッグモード固定。当日以外の日も、任意のメニューも完了にできる
3. 画像が未登録のときはサンプル素材を表示する

## シーズン

記録と画像はシーズンごとに区切る。設定シートの「新しいシーズンを開始」を押すと、
その日から次のシーズンが始まり、前のシーズンはその前日で締まる。

画像・動画はシーズンに属する。新しいシーズンの画像はあらためて追加する。
終わったシーズンは設定シートに残り、期間・達成セット数・開封状況と、
開き切った画像を見返せる。

シーズンは日付の範囲として持つので、記録そのものは日付ごとのまま変わらない。
開始日より前の日は予定日として扱わない。

## データの扱い

登録した画像・動画は端末のブラウザ内（IndexedDB）に、記録と設定は localStorage に保存される。
通信は発生せず、このリポジトリにも画像は含まれない。

ブラウザのサイトデータを消すと、登録した画像と記録も消える。

## 使い方

公開URLを iPhone の Safari で開き、共有メニューから「ホーム画面に追加」する。
以降はホーム画面のアイコンから全画面で起動する。

## 更新時の注意

`app.js` / `app.css` を変更したら、`index.html` と `demo.html` の `?v=` を必ず上げる。
端末に古い `app.js` が残ると、画面の組み立てごと古いままになり、
追加した要素がそもそも存在しない状態になる。
